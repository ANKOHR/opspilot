# 90-second demo script

1. Open Overview and show success rate, approval backlog and cost.
2. Click **Run showcase** to ingest the fictional construction-company enquiry.
3. Open the new run and show extraction, CRM lookup, enrichment, calendar and draft traces.
4. Show that the run is paused at `WAITING_FOR_APPROVAL`.
5. Review the proposed recipient, subject and body in Approvals.
6. Approve the sandbox action and return to the run.
7. Show the completed trace, CRM deal, follow-up task and `sent_in_sandbox` result.
8. Replay the run and point out the new run ID and `replay_of` link.

No real email, CRM record or meeting is sent by the default demo.
